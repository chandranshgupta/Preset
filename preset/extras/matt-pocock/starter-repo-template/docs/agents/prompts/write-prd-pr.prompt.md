# Prompt Skeleton: Write PRD / Spec Pull Request (Single-Pass)

Synthesize the settled requirements and architectural decisions into a clean specification document under `docs/specs/` (or GitHub Spec Issue) using `GLOSSARY.md` terminology and respecting `docs/adr/`.

Include:
1. Problem Statement
2. Extensive Numbered User Stories (`As an <actor>, I want <feature>, so that <benefit>.`)
3. Implementation Decisions (modules, narrow interfaces, schema/API contracts)
4. Testing Decisions (highest seams, external behavior assertions, prior art)
